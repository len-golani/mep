# mep

MEP tools — mechanical, electrical & plumbing utilities for building-services work.

**Status: early scaffolding.** This repository is reserved for small calculators, reference tables and sizing helpers used in MEP design. Nothing usable has landed yet — watch this space.

## Planned contents

- Load / sizing calculators
- Unit-conversion helpers
- Reference tables for everyday MEP lookups

## Why a repo already

So the name, structure and Pages deployment exist before the code does — starting a project is easier than resurrecting one.
